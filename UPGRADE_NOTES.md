# Checkpoint upgrade — 2026-08-07

This package preserves the complete portfolio and adds one final, reversible stylesheet: `checkpoint-upgrade.css`.

## Improvements

- Restored the hero portrait as a dedicated visual stage directly beneath the name on mobile.
- Prevented hero text, buttons, and proof cards from hiding the portrait.
- Standardized left alignment and readable line lengths for professional copy.
- Removed full-justification behavior that creates uneven spacing on small screens.
- Improved heading scale, paragraph rhythm, contrast, section spacing, and mobile tap targets.
- Preserved all projects, internships, credentials, recommendations, CVs, photographs, links, and animations.

The original `styles.css` and `release.css` remain unchanged. To reverse this upgrade, remove the `checkpoint-upgrade.css` link from `index.html`.
